# 🌳 Tablero Ejecutivo - Cambios de Cobertura 2023-2024

Visualización clara y orientada a directivos de la matriz de transiciones entre 2023 y 2024.

## Características
- Cambio neto por tipo de cobertura (barras)
- Top 5 ganadoras y top 5 perdedoras
- Diagrama de flujos (Sankey) interactivo
- Heatmap completo de la matriz
- Soporte para subir nuevo Excel
- Fácil de actualizar y desplegar

## Cómo ejecutarlo localmente

```bash
pip install -r requirements.txt
streamlit run app.py
