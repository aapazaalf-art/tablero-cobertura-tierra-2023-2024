## 📊 Dashboard interactivo para análisis de cambios en cobertura del suelo

Aplicación desarrollada con **Streamlit** y **Plotly** para visualizar transiciones entre diferentes tipos de cobertura del suelo entre 2023 y 2024.

### ✨ Características

- 📈 Visualización de cambios netos por cobertura
- 🔄 Diagrama Sankey interactivo de transiciones
- 🗺️ Heatmap de matriz de transiciones
- 🎨 Colores diferenciados por tipo de cobertura
- 📥 Exportación de resultados (CSV)
- 📱 Diseño responsive
